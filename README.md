## 이 견본이 쓴 설정

| | |
|---|---|
| 템플릿 | 빈 뼈대 · 단순 스택에서 직접 조립한 벤토 그리드 |
| 테마 | 슬레이트 |
| 글꼴 | 모노스페이스 |
| 구성 | 3페이지 (Home · Field · Contact) · 한 페이지(퀵메뉴) |
| 3D | `payphone.glb` + 해변 HDRI 스카이박스 |
| 효과 | 틸트 카드 · 커서 점 · 스크롤 등장 · 부드러운 스크롤 · 스크롤 진행 바 |
| 파트 | 히어로 · 숫자 · 링크 · 갤러리 · 슬라이더 · 3D · CTA · 마퀴 · 커버 · 태그 · 연혁 · 연락처 |
| 사진 | 14장 (여덟 견본 중 가장 많습니다) |
| 용량 | 약 8.4 MB |

**Home** — 벤토 3분할(숫자 · 원칙 · 링크), 녹음 작업 6점 갤러리, 확대 전환 슬라이더, 3D 공중전화, 흐르는 마퀴.
**Field** — 장비 목록을 태그로, 답사지 네 곳을 계절·조건별 기록으로, 동행 제안 CTA.
**Contact** — 스크롤 확대 커버, 작업 순서 연혁, 연락처.

**빈 뼈대**로 시작해 영역 좌우에 칸을 끼워 넣으면 이렇게 크기가 다른 블록을 자유롭게 짤 수 있습니다.

## 직접 열어서 뜯어보기

1. [portfoliomaker.site](https://portfoliomaker.site) 접속
2. 상단 **저장 · 불러오기** 아이콘 클릭
3. **파일에서 불러오기** → 이 저장소의 `tide-and-timber.pbproj` 선택

## Portfolio Maker 는 어떤 도구인가요

- **설치 없음 · 가입 없음** — 브라우저에서 바로 시작합니다
- **틀 → 내용 → 꾸미기 → 내보내기** 네 단계로 끝납니다
- 테마 18종, 글꼴 10종, 파트 15종 이상을 조합합니다
- 3D 모델(`.glb`) 뷰어, 무료 사진 검색, 다크/라이트 토글이 기본 제공됩니다
- 결과물은 **단일 HTML** 또는 **폴더 ZIP** 으로 내려받습니다 — 이 저장소가 그 ZIP 그대로입니다
- 만든 프로젝트는 `.pbproj` 로 저장해 두었다가 언제든 다시 불러옵니다
